# LAB-02 · Amenazas, Vulnerabilidades y Riesgos

## Módulo

**Módulo 1:** Foundations of Cybersecurity (Google Cybersecurity Professional Certificate)

## Objetivo

Diferenciar los conceptos de amenaza, vulnerabilidad y riesgo mediante el análisis de un caso práctico.

## Escenario

Una empresa de comercio electrónico permite que sus empleados trabajen de forma remota. Un colaborador utiliza una contraseña débil y además su computador no tiene las actualizaciones de seguridad instaladas.

## Identificación del caso

| Elemento | Análisis |
|----------|----------|
| Activo | Base de datos de clientes |
| Amenaza | Ataque de fuerza bruta por un ciberdelincuente |
| Vulnerabilidad | Contraseña débil y sistema desactualizado |
| Riesgo | Acceso no autorizado y posible filtración de datos |

## Análisis

### Amenaza

Es el agente o evento con capacidad de causar un daño al activo.

### Vulnerabilidad

Es la debilidad que puede ser explotada por una amenaza.

### Riesgo

Es la probabilidad de que una amenaza aproveche una vulnerabilidad y genere un impacto sobre la organización.

## Recomendaciones

- Implementar autenticación multifactor (MFA).
- Exigir contraseñas robustas.
- Mantener los equipos actualizados.
- Capacitar a los colaboradores en buenas prácticas de seguridad.

## Conclusión

Comprender la diferencia entre amenaza, vulnerabilidad y riesgo permite priorizar controles de seguridad y reducir la probabilidad de incidentes en una organización.
