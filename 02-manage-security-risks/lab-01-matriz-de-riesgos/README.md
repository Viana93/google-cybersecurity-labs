# LAB-01 · Matriz de Riesgos

## Módulo

**Módulo 2:** Play It Safe – Manage Security Risks (Google Cybersecurity Professional Certificate)

## Objetivo

Identificar y priorizar riesgos de seguridad mediante una matriz de probabilidad e impacto para apoyar la toma de decisiones.

## Escenario

Una empresa de comercio electrónico cuenta con una base de datos de clientes, un servidor web y equipos de trabajo para sus colaboradores. El objetivo es evaluar los riesgos más relevantes y priorizar su tratamiento.

## Matriz de riesgos

| Riesgo | Probabilidad | Impacto | Nivel |
|---------|--------------|----------|-------|
| Robo de credenciales | Alta | Alto | Crítico |
| Falla del servidor web | Media | Alto | Alto |
| Pérdida de un portátil corporativo | Media | Medio | Medio |
| Error humano al eliminar archivos | Baja | Alto | Medio |
| Ataque de phishing | Alta | Medio | Alto |

## Análisis

Los riesgos con mayor prioridad son aquellos que combinan una alta probabilidad de recurrencia con un impacto significativo sobre la operación o la información de la organización.

## Controles recomendados

- Autenticación multifactor para reducir el robo de credenciales.
- Copias de seguridad periódicas para minimizar la pérdida de información.
- Capacitación en phishing para los colaboradores.
- Gestión de parches y monitoreo continuo de los servidores.

## Conclusión

La matriz de riesgos permite priorizar los esfuerzos de seguridad y orientar los controles hacia los riesgos con mayor impacto para el negocio.
