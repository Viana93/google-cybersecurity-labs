# LAB-02 · Inventario y Clasificación de Activos

## Módulo

**Módulo 2:** Play It Safe: Gestionar los riesgos de seguridad

## Objetivo

Identificar y clasificar los activos de información de una organización según su criticidad, propietario y nivel de confidencialidad.

## Escenario

Una empresa de tecnología desea elaborar su inventario de activos para fortalecer su gestión de riesgos. Como analista de ciberseguridad, debes clasificar los activos más importantes y definir su nivel de protección.

## Inventario de activos

| Activo | Tipo | Criticidad | Confidencialidad |
|---------|------|------------|------------------|
| Base de datos de clientes | Información | Alta | Alta |
| Servidor web | Infraestructura | Alta | Media |
| Equipos de colaboradores | Hardware | Media | Media |
| Correo corporativo | Servicio | Alta | Alta |
| Página web institucional | Aplicación | Media | Baja |

## Análisis

Los activos con mayor criticidad requieren controles de seguridad más estrictos, ya que soportan la operación del negocio y almacenan información sensible.

## Controles recomendados

- Inventario actualizado de activos.
- Asignación de un propietario por activo.
- Clasificación de la información por nivel de sensibilidad.
- Revisión periódica de los activos críticos.

## Conclusión

Un inventario de activos es la base de una adecuada gestión de riesgos, ya que permite identificar qué recursos deben protegerse y priorizar los controles de seguridad.
